# Number Analyzer

Chương trình phân tích danh sách số nguyên với các tính năng:
- Phân loại số dương, số âm, số không
- Tính tổng và trung bình
- Tìm số lớn nhất

## Cách chạy

```bash
javac NumberAnalyzer.java
java NumberAnalyzer
```

## Cấu trúc chương trình

Chương trình có:
- **Vòng lặp**: Duyệt qua danh sách số
- **Lệnh rẽ nhánh**: Phân loại số (dương/âm/không)
